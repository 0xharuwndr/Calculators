# Calculators

A multi-language repository containing command-line calculator implementations in **C#**, **Java**, and **Python**. This project serves as a showcase and practical comparison of fundamental arithmetic operations, syntax variations, and language paradigms.

---

## 🚀 Supported Languages

| Language | Run Requirement | Source File / Directory |
| :--- | :--- | :--- |
| **C#** | [.NET SDK 6.0+](https://dotnet.microsoft.com/) | `csharp/` or `Program.cs` |
| **Java** | [JDK 11+](https://www.oracle.com/java/) | `java/` or `Calculator.java` |
| **Python** | [Python 3.x](https://www.python.org/) | `python/` or `calculator.py` |

---

## 🛠️ Getting Started

Clone the repository to your local machine:

```bash
git clone https://github.com/0xharuwndr/Calculators.git
cd Calculators
```

---

## 💻 Execution Instructions

Select your preferred language below to run the calculator program:

<details>
<summary><b>🔷 C# (.NET)</b></summary>

```bash
# Navigate to the C# project folder
cd csharp

# Build and run the program
dotnet run
```
</details>

<details>
<summary><b>☕ Java</b></summary>

```bash
# Navigate to the Java folder
cd java

# Compile the source code
javac Calculator.java

# Run the program
java Calculator
```
</details>

<details>
<summary><b>🐍 Python</b></summary>

```bash
# Navigate to the Python folder
cd python

# Run the script directly
python3 calculator.py
```
</details>
