# Multi-Language Calculator Suite

A collections-driven repository featuring standard calculator implementations written in **C#**, **Java**, and **Python**. This project serves as a practical resource for syntax comparison, object-oriented design patterns, and cross-language benchmarking.

---

## 🚀 Overview

This repository contains functional calculator implementations designed to handle fundamental arithmetic operations (addition, subtraction, multiplication, division). Each version adheres to idiomatic code structure and best practices for its respective language ecosystem.

### Supported Languages & Runtimes

| Language | File | Recommended Runtime / Compiler |
| :--- | :--- | :--- |
| **C#** | `Program.cs` | .NET 8.0 SDK / C# 12 |
| **Java** | `Calculator.java` | JDK 17+ |
| **Python** | `calculator.py` | Python 3.10+ |

---

## 🛠️ Quick Start

Clone the repository to your local machine:

```bash
git clone https://github.com/your-username/multi-language-calculator.git
cd multi-language-calculator
```

---

## 💻 Running the Calculators

Select your language of choice below to execute the calculator implementation.

<details>
<summary><b>🐍 Python</b></summary>

```bash
cd python
python3 calculator.py
```
</details>

<details>
<summary><b>☕ Java</b></summary>

```bash
cd java
javac Calculator.java
java Calculator
```
</details>

<details>
<summary><b>💜 C# (.NET)</b></summary>

```bash
cd csharp
dotnet run
```
*(Alternatively, open and run the `.csproj` file in Visual Studio or Rider)*
</details>
